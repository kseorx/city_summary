# Сводка по городу (City Summary CLI)

Утилита командной строки для получения сводки о текущей погоде и курсе выбранной валюты к рублю. Проект демонстрирует корректное взаимодействие с внешними HTTP API: обработку таймаутов, повторные запросы (retry), валидацию ответов и строгое разделение ответственности.

> **Важно:** API-сервисы Open-Meteo и Frankfurter могут быть недоступны или работать с задержками из-за ограничений на уровне сетевых провайдеров в РФ. Для стабильной работы утилиты рекомендуется использовать VPN.

## Требования

- Python 3.10 или выше
- Установленный `pip`
- Стабильное подключение к интернету

## Установка

1. Клонируйте репозиторий и перейдите в папку проекта:

   ```bash
   git clone <url-вашего-репозитория>
   cd city_summary
   ```

2. Создайте виртуальное окружение:

   ```bash
   python3 -m venv .venv
   ```

3. Активируйте окружение:

   ```bash
   # macOS / Linux
   source .venv/bin/activate

   # Windows
   .venv\Scripts\activate
   ```

4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

## Использование

### Базовый запуск (валюта по умолчанию USD)

```bash
python main.py --city Moscow
```

### Указание конкретной валюты по ISO-коду

```bash
python main.py --city Moscow --currency EUR
```

### Вывод результата в формате JSON

```bash
python main.py --city Moscow --json
```

### Пример текстового вывода

```
Город: Moscow
Погода: -3.2°C, clear sky
Теплая одежда: да
USD -> RUB: 92.15
Дорогой курс: нет
```

### Аргументы

| Аргумент | Описание | По умолчанию |
|---|---|---|
| `--city` | Название города (обязательно) | — |
| `--currency` | Код валюты ISO | `USD` |
| `--json` | Вывод в формате JSON | `false` |

### Коды выхода

| Код | Описание |
|---|---|
| `0` | Успешное выполнение |
| `2` | Ошибка аргументов (например, пустое название города) |
| `3` | Город или код валюты не найден в API |
| `4` | Внешний сервис недоступен после исчерпания лимита повторных запросов (retry) |

## Структура проекта

Проект реализует строгое разделение ответственности:

```
city_summary/
├── main.py              # Точка входа CLI
├── clients/             # HTTP-клиенты для внешних API
│   ├── http.py          # Универсальный HTTP-клиент с timeout, retry, валидацией JSON
│   ├── weather.py       # Клиент Open-Meteo: геокодинг + прогноз по координатам
│   └── rates.py         # Клиент Frankfurter API + кэш курса на 5 минут
├── processing/          # Бизнес-логика
│   ├── service.py       # build_city_summary(city, currency="USD") -> dict
│   └── preprocessing.py # Правила warm_clothes (temp < 0) и expensive (rate > 100)
└── tests/               # Модульные тесты
    ├── test_clients.py          # Эмуляция сетевых сбоев, проверка retry
    └── test_preprocessing.py    # Тесты логики preprocessing
```

- **`main.py`** — точка входа CLI: парсинг аргументов (`argparse`), вызов сервиса, вывод в консоль и обработка кодов выхода. Не содержит HTTP-запросов и бизнес-правил.
- **`clients/`** — модули для взаимодействия с внешними API. Реализуют `timeout`, `retry` и преобразование HTTP-ошибок в исключения приложения. Здесь нет вывода в консоль и разбора CLI-аргументов.
- **`processing/`** — бизнес-логика: сборка итоговой сводки и применение правил предобработки.
- **`tests/`** — модульные тесты, включая проверку логики `retry` через `unittest.mock`.

## Реализованные технические требования

- Внешние вызовы — только `GET`.
- `timeout=(3, 10)` на каждый внешний запрос (3 сек на соединение, 10 сек на чтение).
- Не менее двух повторов после первичной попытки при `Timeout`, `ConnectionError` и временных 5xx (500/502/503/504).
- Для `429` учитывается числовое значение заголовка `Retry-After`.
- Аргумент `--currency` — ISO-код валюты, по умолчанию `USD`; если код валюты не найден, код выхода `3`.
- Валидация ответов: проверка `status_code`, `Content-Type` и обязательных полей JSON до передачи в бизнес-логику.
- `JSONDecodeError` перехватывается отдельно и преобразуется в понятное исключение.

## Дополнительные возможности

- **Логирование с `run_id`** — каждый запуск получает уникальный идентификатор, все логи содержат его для сквозной трассировки.
- **Кэш курса валют на 5 минут** — in-memory кэш в `clients/rates.py` снижает нагрузку на внешний API при повторных вызовах.
- **Тесты клиентов через `unittest.mock`** — эмуляция сетевых сбоев (`ConnectionError`, `Timeout`) и проверка корректности `retry`.
- **Типизация** — `type hints` во всех модулях.
- **Флаг `--json`** — вывод результата в формате JSON для машинного чтения.
- **Экспоненциальная задержка с jitter** — пауза между повторами: `2 ** (attempt - 1) + random.uniform(0, 0.5)` для предотвращения шторма запросов.
